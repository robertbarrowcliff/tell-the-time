# Time Telling Helper

**Time Telling Helper** is a simple, child-friendly web app designed to help children practice telling the time using an analogue clock.

It supports children to learn time gradually through clear visual guidance, gentle feedback, and interactive practice.

## What it does

The app helps children practice:

- o’clock and half past
- quarter past and quarter to
- 5-minute intervals
- past and to language
- matching analogue clocks to digital times
- making times by dragging the clock hands

## Features

- Large visual analogue clock
- Colour-coded “past” and “to” sides
- Read the clock mode
- Make the time mode with draggable hands
- Match digital time mode
- Step-by-step helper mode
- Five-star reward system
- Gentle feedback with no timers or pressure

## Who it is for

This app was created to support children who are learning to tell the time. It may be useful for children who benefit from visual, interactive, and low-pressure learning.

## How to use

Open the app in a web browser.

Children can choose from three modes:

1. **Read the clock**  
   Look at the clock and choose the correct time.

2. **Make the time**  
   Drag the long and short hands to make the time shown.

3. **Match digital time**  
   Match the analogue clock to the correct digital time.

Children can also choose different levels of difficulty, starting with simple o’clock and half past times before moving on to quarter times and 5-minute intervals.

## Technology

This app is built using:

- HTML
- CSS
- JavaScript
